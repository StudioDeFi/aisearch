# Contributors

Thank you to everyone who has contributed to AISEARCH ELITE! 🎉

## How to Contribute

1. **Fork** the repository and create a branch from `main`.
2. **Install** dependencies: `npm ci` in each service directory (or use Docker Compose).
3. **Code** your change, following the existing style and conventions.
4. **Test** locally with `docker compose up --build`.
5. **Open a Pull Request** — fill in the template and link any related issue.
6. A maintainer from [@StudioDeFi/aisearch-maintainers](https://github.com/orgs/StudioDeFi/teams/aisearch-maintainers) will review your PR.

## Development Setup

See the [Quick Start](README.md#quick-start) section in the README and the [CLI reference](README.md#cli) for individual service commands.

## Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/) v2.1.  
Please be respectful and constructive in all interactions.

## Reporting Security Issues

**Do not open a public issue for security vulnerabilities.**  
Instead, email [security@studiodefi.com](mailto:security@studiodefi.com) with details.  
We will respond within 72 hours and coordinate a responsible disclosure.
